# Gestor de Notas con TDD y ORM

## 📌 Descripción
Proyecto académico desarrollado aplicando **Test Driven Development (TDD)**, 
Katas de programación, uso de **ORM (SQLAlchemy)** y **automatización de pruebas** 
para gestionar estudiantes y sus notas.

## 🚀 Funcionalidades
- Agregar estudiante y su nota
- Listar estudiantes
- Editar nota de estudiante
- Eliminar estudiante

## 🛠 Tecnologías
- Python 3.x
- Pytest (pruebas unitarias)
- SQLAlchemy (ORM con SQLite)
